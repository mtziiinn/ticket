# 🤖 Discord Bot - Advanced Ticket System

Este é um bot de alta performance para Discord focado em automação de suporte e gerenciamento de atendimento, totalmente desenvolvido em **TypeScript** utilizando a biblioteca **Discord.js v14**.

---

### 🚀 Funcionalidades Chave
- 🎫 **Abertura de Tickets Dinâmica:** Canais de suporte criados instantaneamente através de interações com botões e menus de seleção.
- 📝 **Sistema de Transcripts:** Geração automática do histórico completo de mensagens após o encerramento do ticket para fins de auditoria.
- 📁 **Gerenciamento de Logs:** Registro em canais específicos para ações de staff (abertura, fechamento, usuários adicionados).
- 🗃️ **Persistência de Dados:** Integração nativa com banco de dados para salvar configurações de painéis e estados dos canais.

---

### 🛠️ Stack Técnica
- **Linguagem:** TypeScript (Garantindo tipagem estática e segurança no código)
- **Runtime:** Node.js
- **Biblioteca Principal:** Discord.js v14 (Utilizando interações modernas e Slash Commands)
- **Banco de Dados:** MongoDB (Armazenamento rápido e flexível de dados)
